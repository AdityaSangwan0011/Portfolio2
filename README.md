🚀 Personal Portfolio | Aditya Sangwan
A modern, high-performance portfolio website built with React 19 and Vite. This project showcases my frontend engineering skills, featuring responsive design, interactive UI components, and a 100/100 Lighthouse Best Practices score.

🛠️ Tech Stack
Core: React 19 (Latest Version), Vite (Build Tool)

Routing: React Router DOM v7

Form Management: Formik & Yup (Schema Validation)

Styling & Icons: Bootstrap 5, Remix Icon

Animations: Swiper.js, React Fast Marquee, React Typed, React CountUp

Deployment: Vercel with integrated Analytics

✨ Key Features
Modern State Management: Optimized for React 19's latest rendering patterns.

Form Validation: Professional contact form implementation using Formik and Yup for real-time error handling.

Optimized Performance: Achieving a perfect 100/100 Lighthouse score in Best Practices.

Dynamic UI Components: \* Responsive sliders via Swiper.

Smooth marquee effects for skill displays.

Animated statistics using React CountUp.

SEO & Analytics: Integrated Vercel Analytics to track user engagement and traffic.
